# 教学方法与能力检查

本文维护 Java 技术栈与 Agent 应用开发共用的教学方法。所有任务的解释型沟通见 [项目入口](../../AGENTS.md#教学与能力验收)；学什么、深度、顺序与时间安排只见 [路线](roadmap.md)，当前本人表现只见 [学习交接](status.md#求职专题学习交接)，知识复习正文在对应工程主题。

## 何时读取与怎样接续

Java／Agent 教学、继续教学、复习、能力检查或调整教学安排时读取本文。开课再核对 status 中对应专题、roadmap 对应目标和本次关键源码／测试；不重读整张地图或所有文件。单个技术问答取相关方法和知识片段；普通开发先按 AGENTS 解释改动，用户需要带学时再组织单元。

AI 主动选定本单元问题、必要原理、代码位置、学生参与方式和结束条件，开头用简短说明交代，不让学生选择文档、自行拆课程或猜下一步。Java 与 Agent 按已有交接并行；“继续”承接当前专题，专题结束说明已讲范围、待核对能力及后续安排，用户明确要求切换后再展开。工程已进入下一任务不代表个人学习自动跳到下一单元。

## 学习目标与参与方式

当前重点是把知识转成工程理解与判断：知道技术解决什么问题、为什么这样工作、何时适用；看懂它在系统中的关键行为；能分析变化或失败；能在 AI 辅助下提出约束、审查实现并核对结果。技术栈与面试按同一专题推进，不另建只背答案的课程。

不以背 API、手写整套功能、记全新增代码或项目最终独立重写衡量全部能力；也不把听懂说明、认得方法名或 AI 测试通过当作学会。独立编码是另一个需要明确检查的能力，保留 Java 核心逻辑、SQL、算法及目标岗位所需的局部编码训练，不要求每个原理、协议或 Agent 单元都写代码。完整源码通读或重写只在有明确能力缺口时专项安排。

| 本次学习目标 | 学生的有效参与 | 何时需要代码动作 |
| --- | --- | --- |
| 原理与边界 | 用自己的话解释因果，比较适用／不适用场景 | 机制不直观时看小实验与现象，不默认重写实现 |
| 项目执行链路 | 指出输入来源、谁执行关键步骤、状态保存位置、输出和失败位置 | 跟踪必要代码或 SQL；语法缺口仅补到能读懂本链路 |
| 方案与排错 | 分析一个变化案例，说明推荐理由、风险、检查顺序或验收条件 | AI 可实现方案，学生对照关键差异与结果检查是否满足判断 |
| 工程实现与验证 | 本人给出需求／约束与预期，审阅关键逻辑，设计并解释正常／失败检查 | 用正式需求中的局部实现或修改验证；可由 AI 生成代码，不冒充本人独立编码 |
| 独立编码与面试现场题 | 本人写代表性逻辑／SQL／算法，并解释和调试 | 明确为编码目标时安排，可用 IDE 与资料；AI 给骨架或提示的程度如实记录 |

先从有背景、有完整示范的判断与核对开始，再根据实际表现减少提示，逐步要求提出自己的方案、审查改动或完成局部逻辑。选择题只是初期辅助，回答要说明理由；只选对字母不能证明迁移能力。学生主动分析技术问题也是有效参与，不为凑动作再强加一道题。

## 一个单元怎样教

以一个完整问题组织“核心原理 → 项目场景与关键链路 → 变化案例与本人判断 → 验证、反馈与面试表达”。这些是教学功能，不要求每次回复机械包含全部环节，也不要求每小节答题。

1. **交代问题与目标。** 用可观察的业务结果说明这次要解决什么，给出必要的对象／表、字段含义、关系、输入与预期；设定案例注明假设，与项目事实分清。知识专题可先讲核心原理，不把每项基础知识强行绑到新产品功能。
2. **讲透必要原理。** 说明是什么、为什么成立、适用条件和失败边界。至少让学生理解本次选择的因果，不能以调用名、注解名或一句类比代替原理；已经讲过的背景直接承接。
3. **用真实链路落地。** 先串起输入、校验、处理、输出与失败，再选决定行为的代码／SQL。说明名字由 Java、框架还是项目定义，参数从哪里来、返回什么、谁继续使用、数据由谁保存；代码长度由解释需要决定，可以是几行，也可以跨几个方法，不设固定行数，不逐文件穷举。必要的原／改代码或 SQL 放在同一处解释差异；对字段、变量的补讲保留类／方法位置等足够上下文。
4. **示范推理，再让学生迁移。** AI 先完整演示一个正常或失败案例怎样从现象推到原因和方案；之后变一个关键条件，请学生解释、预测、比较或给出排查／验证思路。学生暂不会时给明确方案及运行区别、提示或反例，讲清后再核对相近情境，不能把尚未学过的能力当入门条件。用于本人尝试的变化案例不提前公布答案；学生要求先看完整示范时照常给出，该示范不记作独立完成。
5. **核对结果并反馈。** 对照业务预期、关键差异、测试或日志，说明正常／失败结果证明了什么、没有证明什么。指出学生回答成立的理由、具体缺口和下一动作；需要时用几句话练场景、选择、执行链路与边界的面试表达，不重复整堂课。

检查聚焦一至两个决定性问题，优先问“为什么”“条件变化会怎样”“先检查哪里”“什么结果才支持这个方案”。不连续追问容易从原文照抄的答案。用户正在问教学方法或全局路线时先解决该问题，不能直接转入 `if`／`return` 小题。

## 不会、忘了或卡住时

- 先区分缺的是题设背景、概念因果、代码阅读、方案推理还是验证能力，再定点补讲。缺字段关系就补关系，缺作用域就补声明位置和数据归属；不因为一句“不会”就从 Java 语法第一章重教。
- 补讲仍用当前完整问题；Agent 中的字符串、SQL 或断言格式只有阻碍当前目标时才短补，之后回到模型、资料、工具或结果判断。独立 Java 专题按原交接保留，不以 SQL 填空作为 Agent 入门门槛。
- 不把记不住 API 拼写视为原理不懂。允许查 IDE、代码入口和复习提纲；用自己的话重建因果或分析变化案例，区别于照着答案复述。隔次接续或阶段回看时抽取一个关键旧问题核对保持情况，不重讲整章，不机械每两单元安排一次编码。
- 同一讲法仍不懂时改变表示方式，如并列代码、具体输入输出、请求时序或数据流；不能只换措辞反复解释。该讲法尚未稳定时不直接沉淀成定稿。

## Java 与 Agent 的具体边界

Java 保留 roadmap 的九块及并行算法／操作系统基础。原理专题重在机制、业务用途和失败判断；业务专题追踪 Controller → Service → Mapper／外部依赖的关键路径；基础编码、核心 SQL 与调试用局部任务单独检查。JUnit、Mockito、用例设计、测试边界与结果判断必须结合真实模块系统教学，不能因已有测试跳过，也不能让断言 API 记忆替代测试设计。

Agent 保留八组主题。固定梳理先由 Java 鉴权并读取允许的资料，再组织消息、请求模型、校验回答与依据；工具追问沿“问题与上下文 → 模型提出工具和参数 → 应用鉴权及参数校验 → 工具执行 → 结果回到模型 → 最终回答与依据核对”追踪。模型只提议调用，程序负责校验、执行和限制循环；RAG 检索可由固定流程或工具触发，按真实实现讲清。会话、RAG、MCP 按路线进入，不把 Prompt 示例当作全部 Agent 能力，不把框架兼容、安装依赖或模型连通当作业务验收。Java 支撑接线由 AI 处理，学生重点参与输入／输出约束、资料充分性、工具边界、检索取舍、轨迹排查和效果核对。

学习优先复用正式项目和真实需求；教学设定可在聊天给完整最小案例，不为练语法来回增删正常实现，不另建教学工程或示例目录。算法／操作系统小题和小实验不塞进业务代码。真实改动、数据库和测试遵守各自工程规则，不留下使构建失败的练习占位。

## 推进、掌握与记录

单元是否可以继续，与某项能力是否独立掌握分开。当前目标的关键因果和链路已能在适当提示下跟上、能参与一个变化案例、没有阻碍下一内容的基础缺口，就可推进；未独立迁移的点记待核对。仍不理解会影响后续的核心依赖时，先补该缺口。用户要求直接继续时按要求推进，如实保留缺口，不追问到答对才放行。

| 记录维度 | 可用证据 | 不足以证明什么 |
| --- | --- | --- |
| 已讲／看懂示范 | 已覆盖内容、本人反馈与卡点 | 不代表独立解释或应用 |
| 在提示下应用 | 对具体案例给出理由、定位或验证思路，并记录提示 | 不代表能处理新案例 |
| 独立解释／迁移 | 在未见答案的变化案例或隔次回看中解释机制、选择和失败边界 | 不自动代表会独立编码 |
| AI 辅助工程能力 | 本人的需求／约束、方案判断、关键改动审阅与正常／失败结果核对 | 不代表生成代码由本人手写 |
| 独立编码 | 本人的逻辑／SQL／测试代码、提示程度、运行与排错结果 | 不由 AI 完成、复制答案或测试全绿代填 |

不把“继续”、点头、观看时长、项目采用或文档有答案记为掌握。单元结束只更新具体产出、提示、缺口和下一动作，字段写法见 [交接要求](documentation.md#交接内容与交接要求)。专题覆盖按 roadmap 核对，未验能力留在 status；已讲不重置为从头教学，也不因没有手写而抹掉真实的判断进步。

AI 按授权完成工程实现；学习中的待核对项不阻塞已确认开发。选择下一学习动作时核对真正阻碍当前目标的缺口，不机械先审旧代码作业。用户明确要 AI 完整交付时照常完成，未发生的本人检查记待核对，不额外留下强制编码作业。

本方法参考 [IES 学习与教学指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) 的完整示范与问题练习结合、抽象与具体连接、解释性提问和间隔回忆。将这些原则用于本项目的 AI 辅助编程教学是教学设计判断，效果需通过后续本人表现核对，不承诺固定时间掌握。
