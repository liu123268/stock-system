## 1. Spring Security 与 JWT 认证闭环

状态：已验证

### 业务问题

保护工作台和后续空间数据，避免仅依赖前端保存的登录状态。

### 实现

- BCrypt 密码摘要；
- 登录签发 JWT；
- `JwtAuthenticationFilter` 验证 Bearer Token；
- 无状态 SecurityContext；
- `AuthenticationEntryPoint` 统一 HTTP 401 与 JSON；
- `/api/auth/me` 查询当前有效用户。

### 证据

- 后端认证、安全过滤器和异常处理代码；
- 注册、登录、错误密码、JWT、401 和当前用户集成测试；
- 前端 Pinia、Axios 拦截器和路由守卫；
- 真实浏览器认证冒烟测试。

### 当前边界

尚未实现 Refresh Token、主动吊销和多设备会话管理，简历中不能声称已经具备。

## 3. 空间级数据隔离

状态：开发中，普通用户空间访问边界已验证

### 目标

任何空间业务请求都先根据当前用户验证 `workspace_member`，防止通过修改 URL 或参数读取其他空间数据。

### 已有证据

- 创建空间与 OWNER 成员关系在同一事务内写入；
- 空间列表只返回当前用户的有效成员关系，详情接口对非成员返回 404；
- URL 表达当前空间，前端不把当前空间 ID 重复写入 localStorage；
- 后端空间集成测试、前端 Store 单元测试和注册登录到创建空间的真实 Chrome 闭环通过；
- 邀请码使用 `SecureRandom` 生成，生成/停用用当前邀请 ID 防止旧页面覆盖新状态，完整代码只返回当前 OWNER；
- 加入事务统一按空间、邀请、成员加行锁，6 人竞争 5 次时准确得到 5 次成功和 1 次用尽，计数没有超限；
- 成员退出与移除只更新同一条生命周期记录，重新加入不制造重复成员；被移除者旧码拒绝、新码恢复；
- 所有权转让只更新空间表的唯一所有者字段，并发转让只有一个请求成功；
- 双账号真实 Chrome 闭环已覆盖完整成员生命周期和所有权转让；
- OWNER 归档在同一事务内更新空间状态与归档时间并停用当前邀请码；归档空间对有效成员只读，普通 MEMBER 仍可主动退出；
- 恢复按 `ARCHIVED_BY_OWNER/ARCHIVED_BY_SUPER_ADMIN` 来源隔离，显式 Mapper SQL 与数据库检查约束共同保证状态和归档时间一致；
- 空间页面按 401、成员关系失效、空间归档和网络失败分别处理，退出登录清空认证与全部空间运行期缓存；
- 双账号真实 Chrome 闭环已覆盖 OWNER 归档、MEMBER 只读重入、OWNER 恢复和退出登录；
- 浏览器测试的现行隔离、历史污染修复与清理证据见 [BUG-003](../engineering/bugs/BUG-003-browser-test-database-boundary.md)。

### 成为简历亮点前还需要

- 更完整的跨空间越权集成测试；
- 完成后的架构和面试文档。

## 4. 自动化测试数据库硬隔离

状态：已验证

### 业务问题

真实浏览器测试会经过完整 HTTP 和数据库链路，单靠 test profile 名称或事后清理无法保证不会污染需要保留的开发数据。

### 实现与证据

- dev/test 数据库 URL 分离，开发与浏览器测试使用两套固定启动入口和不同端口；
- test 后端启动时读取真实 JDBC catalog，不是 `stock_system_test` 就拒绝启动；
- 浏览器脚本在第一次写入前通过 test-only 接口二次核对运行中后端；
- 测试数据使用唯一标识并按外键顺序精确清理；
- 该次检查数量和清理证据统一见 [BUG-003](../engineering/bugs/BUG-003-browser-test-database-boundary.md#5-数据处理与验证)。

### 当前边界

当前是本机 MySQL 隔离方案；尚未接入 CI 和 Testcontainers，不能声称每次测试都创建全新的临时数据库实例。

## 5. 股票研究首个纵向闭环

状态：已验证

### 实现与证据

- 用 `stock → workspace_stock → research_cycle → stock_opinion` 分离标准身份、空间关系、关注周期和可追加观点；
- 行情提供者在事务外取快照，事务内重新校验空间与成员并原子写入，数据库约束保护活动周期和 INITIAL 观点唯一；
- 共享列表一次返回页面首屏所需的股票、行情、周期、添加人和初始观点，非成员不可见、归档成员只读；
- Vue 页面、Pinia Store 和 API 层完成搜索、候选选择、表单提交、列表刷新及空/错/加载状态；
- 后端 38 项、前端 15 项单测及双账号真实 Chrome 流程通过，测试数据和测试进程均已清理。

### 当前边界

行情仍为明确标识的本地模拟数据；多人观点、结束关注、重新开启周期和真实行情提供者尚未实现。
