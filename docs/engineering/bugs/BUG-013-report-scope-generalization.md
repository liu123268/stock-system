# BUG-013：报告引用正确，但摘要扩大了原文对象范围

日期：2026-10-18。影响报告事实的模型重述，和财务数字单位保护是不同问题。

## 实际错误与根因

原文对高粱、小麦分别描述采购模式，只对“其他原辅料及包装材料”说明主要按生产销售计划集中采购。报告六题真实 v8／v9 的组合题却概括为“原料采购主要根据生产和销售计划执行”，扩大了原句对象。股票、报告版本、来源编号与页码都正确，但原文不能充分支持这句话；v9 加强 Prompt 后仍复现，不能视为只修一句规则就已解决。

v9 证据 `target/agent-reports-real-20261018-181506-802fde91/results.json`，Codex 对照 `target/report-answer-v9-source-review.json`。本轮金额和百分号正确，严格来源支持仍只能计 5／6。已有检索命中、合法引用和数值校验都不检查自然语言适用范围，不把一次坏例推断为某个具体模型参数导致。

## 当前修复与取舍

[ResearchReportAnswerSupport](../../../src/main/java/com/stock/system/agent/service/ResearchReportAnswerSupport.java) 对新回答中带报告引用的事实段落，直接从本次授权材料交付完整受审原文和真实页码，保留“其他”、计划语气和原报数字，按来源去重。模型仍负责选择相关来源、整理成员观点和解释财务依据；后两类必须与报告摘录分段，混合引用拒绝，不为生成摘录静默删除其他依据。最终段数／长度、原文授权和保存前检查继续生效。

这选择了受限的摘录回答方式，不能宣传成模型自由概括能力已提高，也不能保证模型选对任何问题的来源。未带报告引用的概念文字与历史正文不作追溯改写，原文是否支持本次问题仍须核对；后续如恢复报告自由概括，需要独立语义评估，不能移除摘录保护后沿用本次结论。

## 验证与复习

[确定性检查](../../../src/test/java/com/stock/system/agent/service/ResearchReportAnswerSupportTest.java) 保留实际扩大范围坏句、计划改写、重复引用、其他材料不受影响及混引拒绝。[真实结果离线回放](../../../src/test/java/com/stock/system/agent/service/ResearchReportAnswerReplayTest.java) 仅显式指定 target 内已有实验结果时启用，核对原文身份后通过摘录／数字保护，另存输入哈希和“新增模型请求为 0”元信息；原结果不覆盖。离线回放不是新版本真实模型运行，也不代填用户质量验收。最新结果与预算只见 [任务第 28 节](../../specs/004-research-agent/tasks.md#28-报告六题真实对照与财务正文防错2026-10-18)。

复述时从“原文对谁成立”检查摘要是否扩大范围，再说明为何这里采用抽取式摘录，以及它对自由概括和工具选择仍有哪些限制；不要把所有幻觉问题归结为温度或 Prompt 不够长。
