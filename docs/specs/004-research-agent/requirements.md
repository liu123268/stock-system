# SPEC-004：单股研究梳理与追问需求

状态：已确定首个场景的入口、结果组织、首次报价、原文弹窗、个人对话延续与主动清空策略；其余细则已有推荐草案，待用户集中确认，尚未实施。

日期：2026-10-08。用户接受研究梳理结果方向，并授权检查与优化组织方式。四种信息保留，将证据缺口和待验证问题合并展示，避免重复。全局产品范围与权限边界见 [V2 需求](../../product/requirements-v2.md)，技术规划见 [技术栈](../../architecture/technology-stack.md#32-v2-agent-技术规划基线)。

## 1. 入口与结果

- AG-001：在单股研究详情中，针对选定的一个研究周期点击“研究梳理”，查看带依据的结果，并在结果下方继续输入追问。先明确当前股票与周期，具体入口位置和弹窗布局在设计时落实。
- AG-002：结果顶部显示最新可用报价（见 AG-011）及一句简短概括，再展示“观点变化”“成员观点”“待核对事项”三块。保留判断变化、成员差异／共识、证据缺口和待验证问题四种信息，不要求每次生成相同数量或长度的段落。
- AG-003：“观点变化”说明谁在何时调整了倾向或理由，并引用对应前后观点。没有可确认的变化时简短说明；只读到部分资料时，结论限定为本次读取范围，不宣称整个周期没有变化。
- AG-004：“成员观点”列出用于比较的各成员倾向、主要理由和观点日期；当前比较使用本周期最新可见且未撤回的观点，历史调整放在“观点变化”。明确真实共识或差异，不为固定版式制造分歧，也不把某条观点的倾向当成成员至今未变的判断。
- AG-005：“待核对事项”按问题逐条展示需要核对什么、缺少／尚未读取什么资料、目前是否已核对及对应原观点。证据缺口与后续问题放在同一条，避免两块重复列举；提出一个问题不表示已经完成条件核对或取得外部资料。
- AG-006：结果下方允许自由追问；初次梳理的固定结构用于帮助用户理解研究进展，不要求每次追问都重新输出三块完整结果。具体问题范围和工具行为继续讨论。

## 2. 依据与不足

- AG-007：观点归纳须引用实际读取、当前有权展示且能支持相应结论的原观点；引用可定位并查看原文。读取范围不足的说明依据实际读取信息，不伪造一条观点来证明“没有资料”。引用未读取或已撤回的正文不得作为有效依据。
- AG-008：结果注明选定周期及实际覆盖范围，区分完整读取、截断和本次未查询的资料；有行情或外部资料时同时说明来源和数据时间。展示统计和具体读取上限待设计，不由模型猜测。
- AG-009：成员判断、已读取资料能证明的事实、助手提出的待查问题分别表达。例如“成员担心盈利能力”不能改写成“公司盈利能力已经下降”，“本次没有读取公告”不能改写成“公司没有发布公告”。
- AG-010：没有可用观点时说明资料不足；仅有一位成员或一条观点时，不编造多人比较或判断变化。没有真实分歧、变化或待查问题时允许简短说明，不为凑齐内容添加无依据结论。
- AG-011：2026-10-08 用户明确要求首次结果默认带价格。展示最新可用报价、币种、报价时间和来源，直接使用后端核验后的同一行情快照字段；模拟数据如实标识，不由模型猜测或改写价格。报价缺失／超时时显示暂不可用，观点梳理仍可完成；数据时效由报价时间说明。最新报价与选定周期的起止时间分清，不能当成历史周期的结束价。

### 2.1 引用查看与个人对话

2026-10-08：用户接受原文弹窗、保存对话及默认个人可见方案；进一步讨论保存用途后，同意简易保存与主动清空策略，具体要求见 AG-015、AG-016、AG-019。

- AG-012：点击观点引用，在当前页面打开对应原文弹窗，展示作者、日期、倾向和原始内容；关闭后保留梳理结果、聊天位置与输入。涉及多条引用时可逐条查看，具体尺寸及布局在设计时确定。
- AG-013：查看引用时按 AG-007 校验当前可见性；原观点已撤回或用户已失去访问权限时，提示当前无法查看，不用生成时缓存的旧正文冒充当前可见原文。
- AG-014：首次梳理作为本段对话起点，追问承接必要的先前问答与当前有效资料；问题指代不清时先澄清，不自行猜测人物或研究对象。
- AG-015：刷新或离开后返回，可以恢复当前用户在该空间、股票和研究周期下的一份可延续对话。保存记录不等于每次将全部聊天历史送给模型，回答仍受输入长度与当前授权约束；保存及清空策略见 AG-019。
- AG-016：切换股票或研究周期时，显示该研究对象对应的个人对话；首次使用时开始新对话，返回已有对象时可继续原记录，各对象的上下文独立。
- AG-017：第一版对话默认仅当前用户可见；空间内原有正式研究观点继续共享，个人追问和助手回答不自动发布为成员正式观点。共享生成结果的功能另定范围。
- AG-018：历史回答保留生成时的数据时间，恢复记录不会刷新其中的报价或核对状态；问当前情况时按需重新读取。恢复和继续对话仍沿 AG-007、AG-013 处理撤回与权限变化，不能借旧回答恢复受限原文。
- AG-019：首版个人对话保留到用户主动清空，不增加自动过期、独立历史会话列表、搜索或重命名功能。清空当前研究对象的个人对话后重新开始，其他对象、其他成员的聊天和空间正式观点不受影响；清空不重置已经发生的调用用量或费用。删除、生成中处理及迟到回答保护的技术机制在设计中落实。

## 4. 结果验收场景

以下为待实施的验收要求，尚未验证：

| 输入情形 | 应看到的结果 |
| --- | --- |
| 正常取得首次报价 | 顶部默认展示后端同一快照中的价格、币种、报价时间和来源；报价不冒充历史周期结束价 |
| 首次报价缺失或超时 | 顶部明确显示报价暂不可用，仍能完成有依据的观点梳理，不填入模型猜测价格 |
| 一位成员先看好、后调整为中立；另一位成员担心盈利能力 | 正确引用前后变化，按各自最新可见观点比较；“担心盈利”仍标为成员判断，资料缺口与待查问题合并 |
| 多位成员倾向和理由接近，没有可确认变化 | 简短说明本次范围内未发现明显变化或分歧，不能刻意生成对立观点 |
| 零条观点或只有一位成员的一条观点 | 明确资料不足或无法比较，不生成虚构变化和成员差异 |
| 读取截断，或没有查询公告／财报 | 明确覆盖范围与未查询资料，不声称完成整个周期或所有外部证据的核对 |
| 原观点已撤回或当前用户失去访问权限 | 不展示不可访问正文，不借旧生成内容恢复受限原文；具体会话处理在设计时落实 |
| 点击引用并关闭弹窗 | 打开对应原观点，关闭后梳理结果、聊天位置和正在输入的问题仍保留 |
| 刷新、离开后返回，或切换研究对象再返回 | 恢复当前用户对应对象的对话；不混入其他用户、空间、股票或周期的消息，旧报价仍保留原时间 |
| 主动清空当前研究对象的个人对话，再次返回 | 该对象从新对话开始，迟到回答不恢复已清空内容；其他对象、其他成员聊天、正式观点及已发生用量不受影响 |
| 同空间其他成员查看该股票 | 可查看其有权访问的正式观点，不能读取另一位成员的个人 AI 对话；个人聊天不自动成为共享研究记录 |
