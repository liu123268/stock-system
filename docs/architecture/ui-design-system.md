# 基点前端视觉设计系统

## 当前视觉：基点 V2

2026-09-29 用户确定采用指定 `stock-workspace-demo-v1.html` 的视觉风格。2026-09-30 进一步要求预览的功能内容与当前系统一致，并将名称改为“基点”；随后用户否定源码生成预览，已恢复原 V2 设计；后续补功能需保留其构图，不能以现有页面套主题替换。正式源码已完成公共视觉、空间外壳及选择页（UI-01）、共享自选（UI-02）、行情页／初始观点／共用图表（UI-03）、研究详情（UI-04）、空间概览（UI-05）、成员与设置（UI-06）、公开首页（UI-07）、认证与个人资料（UI-08）、治理后台（UI-09）；UI-10 的收口验证见任务证据，旧实现已从正式源码退出。实施范围与边界见 [SPEC-003 需求](../specs/003-ui-migration/requirements.md)，参考基线、字段对应及预览机制见 [迁移设计](../specs/003-ui-migration/design.md)，顺序和证据见 [任务](../specs/003-ui-migration/tasks.md)。

以下为唯一现行视觉规范。旧轨道、旧主题参数和旧认证构图已退出；历史组件隔离教学保留在前端工程，不作为当前页面要求。

### 色彩与表面

- 以预览的暖白背景 `#FAF8F4`、面板 `#FFFDF9`、次级表面 `#F3EFE7`、墨色 `#191510`、细线 `#E3DDD1`、雾蓝强调 `#6E9FC4` 与深蓝 `#4E6E88` 为视觉基准；将其接入项目语义变量，不把每页复制一套变量。
- 保留预览的低对比坐标纸与轻噪点表达、细线分区、轻圆角和留白层级；图表和长正文应清楚可读，装饰不遮挡控件、不拦截操作、不跟随鼠标抖动。
- 上涨／下跌颜色服务行情语义，观点立场使用中性标签；错误、危险操作和其他状态另有语义，不能让装饰色冒充涨跌。
- 辅助正文至少满足 4.5:1 对比度，不机械复制预览偏淡的 `--dim`；边界和装饰的淡色不能直接当小字号正文色。

### 排版与控件

- 采用预览的中文衬线展示标题、无衬线正文、等宽数字与时间的层级方向，参考字体为 Noto Serif SC、Noto Sans SC／Space Grotesk、IBM Plex Mono。提供宋体、系统无衬线和等宽回退，外部字体失败时内容仍可读，禁止靠字体加载隐藏正文。
- 普通业务正文和控件保持易读；使用真实长名称、观点和多行反馈适配宽度，窄屏由多列转单列。不把预览固定文本长度当布局约束。
- 按预览统一按钮、输入框、标签、工具栏、表格和提示。补齐 focus、disabled、loading、error 状态；保留语义标签、表单 label 与现有校验反馈，不复制内联 onclick 或全局 DOM 路由脚本。
- 首页可以保留预览的构图和装饰节奏；业务内容默认可见，动效不得让快速切页、未触发观察器或后台标签页的内容永久透明。减少动态偏好下停用持续旋转、跑马灯与滚动显现，并保留静态内容。
- 首页走马灯不设暂停按钮，鼠标悬浮或焦点进入时继续滚动；减少动态偏好仍按上一条保留静态内容。此要求已应用于内容补齐副本和正式首页，原始设计备份保留。
- 原 V2 缺少的完整登录、注册、个人资料及管理表单已在内容补齐副本提供设计对应；正式页面用同一控件和分段语言接入真实校验、提交与反馈。具体位置与业务文案适配只在 SPEC-003 design 维护。

### 验收与迭代

保留键盘操作、明确焦点、状态不只依赖颜色和桌面／手机无页面横向溢出的要求；数据表需要横向阅读时使用局部可操作滚动区。字体、噪点和图表应检查实际浏览器加载与性能，不能凭源码宣称视觉效果已经验证。

每块先复用已确定的视觉和组件规则，再对照真实内容调整局部尺寸及文案；实际完成证据只写对应 tasks。全站使用一组共享语义令牌；页面只定义布局和有业务意义的局部样式。旧演示不进入生产路由，独立 V2 参考及各块前后证据保留。

## 共享主题与组件职责

`frontend/src/styles/main.css` 的 :root 维护色彩、字体、圆角、间距、缓动与层级；research-theme 只附加坐标纸、轻噪点和页面表面。挂到 body 的提示也能取得共享颜色，但定位、纹理和 Element Plus 映射仍由提示类明确设置；不把背景装饰挂到所有浮层。

空间外壳和选择页、认证布局／表单、资料、治理布局按各自任务控制信息密度与响应式。局部 CSS 保持作用域，尤其后台表格规则不能污染空间页。首页、认证使用品牌标题，业务表格／按钮保持正文与数字字体。完整映射见 [迁移设计](../specs/003-ui-migration/design.md)。

按钮、输入、状态和确认区使用明确标签与完整焦点／禁用／错误行为；危险动作说明目标与后果，不只改变颜色。优先保留已实现的内联确认与自然流反馈，提交锁定和取消行为按真实业务处理。长表格在自己的区域横向滚动，页面本身不横向溢出。

## 可访问性要求

以 WCAG 2.2 AA 为最低目标，正文对比度至少 4.5:1；交互支持键盘且焦点清楚，状态不能只靠红绿区分。主要内容由各页 main 表达，应用根容器不再嵌套第二个 main；跳过链接能聚焦内容。

减少动态偏好下停止持续动画并保留静态构图，行情组件沿原生命周期关闭对应动画；减少动画不意味着取消数据读取，也不能把条件挂载换成 CSS 隐藏。浮层、提示、固定顶栏、时间线锚点与自然流长表单分别检查遮挡和裁剪。

## 迭代方法与边界

复用当前令牌与骨架，结合真实字段、作者、时间和状态调整局部尺寸；不复制设计演示的模拟角色／数据脚本。公开首页的示意曲线保留局部示意标识，正式行情继续复用 ECharts 与后端数据。

原独立 V2、内容补齐副本和各块截图只作为设计与验收证据，不是第二套生产界面。旧设计演进的组件职责教学见 [前端工程](../engineering/frontend.md#五历史视觉演进与组件职责)，当前实际验证和未执行边界只见 [SPEC-003 tasks](../specs/003-ui-migration/tasks.md)。
